Mount the widget where users land: - React: import { ChatWidget } from "chatbotlite/react"; <ChatWidget endpoint="/api/chat" title="..." /> - HTML: chatbotlite.mount({ endpoint: "/api/chat", title: "Acme" }) 4. TypeScript types ship in the package — see node_modules/chatbotlite/dist/react/index.d.ts.

Why solo devs ship with chatbotlite

What you don't have to build yourself.

Knowledge is a markdown file

No vector DB. No RAG infra. Write services, hours, pricing in a .md file — anti-hallucination guards keep the bot grounded.

Multi-LLM with fallback

Groq llama-3.3-70b by default (free, fast). Add OpenAI / DeepSeek keys — the chain fails over automatically. No single provider lock-in.

Stripe + Calendly built-in

Payment cards, scheduling, file upload — tool cards render inline in the chat. Paste a Stripe Payment Link or write a 5-line handler.

Per-vertical fine-tuning

extraInstructions appends behaviour rules. systemPromptTransform rewrites our defaults. Three customization tiers.

Anti-hallucination guards

Phrase redlines + optional LLM input/output judges. The bot never invents prices, availability, or appointment confirmations.

Apache 2.0, fully yours

npm package + source on GitHub. No SaaS subscription, no per-conversation pricing, no vendor lock on your customer data.

All 6 demos run on a single chatbotlite npm package + <script> tag.
